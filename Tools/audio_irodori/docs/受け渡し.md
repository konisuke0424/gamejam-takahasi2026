# 受け渡し

- `mother_01`〜`mother_11`: 本物の母親（11本）
- `monster_01`〜`monster_08`: こだま（8本）
- `chase_01`〜`chase_02`: 追跡時（2本）
- `catch_01`: 捕獲時（1本）

左右・シーン内の 3D 定位はゲーム担当者側で付与。**「どこから聞こえるか」は焼き込まない。**

near / far は WebGL で距離に応じて切り替える **2 種類の WAV** であり、こちらで `assets/export` に用意する。

ゲーム組み込み: `assets/export/`（各 ID の near + `_far`）→ `python Tools/audio/sync_irodori_export.py` → `Assets/Game/Audio/Voices/`。`mother_11` → `mother_found`。
